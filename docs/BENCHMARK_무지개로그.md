## ① 블로그 개요

- 닉네임 **무지개로그**. 마무리 CTA에서 "무지개로그" 5글자를 무지개색으로 칠하는 시그니처.
- 최근 9일 30건 = **하루 3.3건**. 슬롯 이원화: 아침 06~09시(장 전 경제지표 브리핑, 고정 시리즈)
  + 오후 13~19시(이슈·꿀팁·드라마).
- 카테고리: 경제 60% / 꿀팁 20% / NEWS 13% / 엔터 7%. 댓글 반응(이웃 전환)은 꿀팁이 최고.
- 수익화: 제휴·외부링크 **0건** — 순수 애드포스트 + 이웃 증식. 긴 세로 스크롤 자체가 노출 장치.

## ③ 구조 골격 (모든 글 동일)

`[표지] → [인사 인트로] → (구분선 → 섹션 배너 이미지 → 이모지+볼드 소제목 → 본문) × 8~12 → [핵심 포인트 요약] → [이웃신청 CTA] → [마무리 이미지]`

1. **서론(100% 동일)**: 첫 줄 "안녕하세요. 😊" → 주제 3~6줄 → 훅(충격 수치·의문문 볼드) →
   "~살펴보겠습니다. 😊" (150~250자). 뉴스류는 "추측·미확인 내용 제외" 신뢰 장치.
2. **경제지표 시리즈 섹션 순서(고정)**: 미국 3대 지수 → 필라델피아 반도체 → WTI → 국채/환율 →
   달러인덱스 → VIX → 금 → 비트코인 → 중국 → 🇰🇷 국내 증시 예상 → 투자자 핵심 포인트.
3. **지표 섹션 내부 공식**: `✅ 지표명(볼드·파랑) 수치(검정) (등락률)(볼드·상승 빨강/하락 파랑)`
   → 팩트 1문장 → 해석 1~2문장 → **국내 업종/종목 착지 1문장**("국내에서는 ✔삼성전자 ✔SK하이닉스…").
4. **색상 규칙(무결점 일관)**: 상승=#f12f22 빨강 / 하락=#0076c8 파랑, 항상 볼드. 등락률 괄호에만.
   파랑은 ①②③ 넘버링·용어 정의 헤더에 재사용.
5. **마커 사전**: ✅=핵심 지표·체크리스트 / ✔=관련 종목 나열(1줄 1항목 볼드) / ①②③=원인(파랑 볼드)
   / 📌=요약 문단 첫머리. 소제목 이모지는 내용 1:1 매칭(🛢유가 💵환율 😨VIX 🥇금 ₿코인 🇨🇳 🇰🇷).
6. **마무리(100% 동일)**: "💙 투자자가 꼭 기억해야 할 핵심 포인트 🌈" → 📌 재요약 3~5문단(수치 재언급)
   → 균형 행동 지침(개연 화법 면책) → 이웃신청 CTA(무지개색 브랜드명) → 마무리 이미지.
7. **해석 화법**: 전부 개연형 — "~가능성이 있습니다 / ~로 해석됩니다 / 단정하기는 어렵습니다".

## ④ 우리 글과의 핵심 차이

1. **줄바꿈 밀도** — 한 문장을 13자 안팎 의미 단위로 절단(조사·연결어미 뒤). LLM 문단을 그대로
   넣으면 모바일 35~40자 벽돌인 것과 최대 체감 차이.
2. **전체 가운데정렬** — 인용구 빼고 100%.
3. **빈 문단 리듬** — 문장 묶음 사이 규칙적 공백(전체의 1/4).
4. **이미지=섹션 앵커** — 구분선+배너+소제목 3종 세트, 이미지 수=섹션 수.
5. **표 미사용** — ✅리스트+색상으로 대체(모바일 우선).
6. **매 섹션 국내 착지** — 글로벌 지표 나열로 끝내지 않음.

## ⑤ 이식 규칙 (우선순위)

**P1 시각 구조**: ①전 문단 가운데정렬(인용구 제외) ②문장 10~20자 의미 단위 2~5줄 분할
③문장 묶음 사이 빈 문단 ④섹션=구분선+배너 이미지+이모지 소제목 ⑤본문 2,000~2,800자·섹션 8~12개.

**P2 서식 문법**: ⑥수치 = 지표명(파랑 볼드)+수치(검정)+(등락률)(상승 빨강/하락 파랑 볼드)
⑦마커 사전 ✅✔①②③📌 ⑧소제목 이모지 1:1 매칭 ⑨강조는 볼드 우선(40~80개), 색은 등락·넘버링만.

**P3 콘텐츠 골격**: ⑩서론 고정 패턴 ⑪경제 시리즈 섹션 순서 고정 ⑫지표 섹션 4단 공식(수치→팩트→
해석→국내 착지) ⑬마무리 고정(재요약📌+행동 지침+CTA) ⑭개연 화법 통일 ⑮제목=훅+총정리+이모지.

**P4 운영**: ⑯슬롯 이원화(장 전 브리핑+오후 이슈) ⑰포트폴리오 6:2:1.5:0.5 ⑱무제휴 순수
애드포스트 전략(우리가 제휴 얹을 땐 별도 실험으로).
